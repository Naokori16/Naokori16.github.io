FAQ

Pertanyaan yang sering muncul

Belum menemukan jawabannya? Tanyakan langsung lewat WhatsApp.

Berapa lama pengerjaannya?

Rata-rata 2 sampai 5 hari kerja tergantung jenis dan kerumitan desain. Estimasi pastinya saya sampaikan saat konsultasi.

Berapa kali boleh revisi?

Setiap paket mendapat 2 kali revisi gratis. Revisi tambahan dikenakan biaya kecil sesuai kesepakatan.

Bagaimana sistem pembayarannya?

DP 50% di awal, pelunasan setelah desain disetujui dan sebelum file final dikirim. Pembayaran lewat transfer bank atau e-wallet.

Apakah melayani di luar kota?

Bisa. Semua proses dilakukan online lewat WhatsApp dan file dikirim digital, jadi bisa dari mana saja.

File apa yang saya terima?

File final dalam format PNG, JPG, dan PDF. File sumber (AI/PSD) tersedia untuk paket tertentu.

Siap mulai proyekmu?

Ceritakan kebutuhanmu, konsultasi pertama gratis dan tanpa kewajiban memesan.
